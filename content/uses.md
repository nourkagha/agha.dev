## 🖥️ Software

### 👨🏻‍💻 Development

- ⚙️ **Operating system:** [Pop!_OS](https://system76.com/pop) — Ubuntu-based Linux and my daily driver for development, productivity, and gaming.
- 🪟 **Desktop environment:** [COSMIC](https://system76.com/cosmic)
- ⌨️ **Terminal:** [COSMIC Terminal](https://github.com/pop-os/cosmic-term)
- 🐟 **Shell:** [fish](https://fishshell.com) — a friendly, interactive shell with syntax highlighting, autosuggestions, and tab completions out of the box, giving me a cleaner experience than zsh with plugins.
- 🧩 **Shell plugins:** [Fisher](https://github.com/jorgebucaran/fisher) — plugin manager for fish. I mainly use [plugin-git](https://github.com/jhillyerd/plugin-git) for git aliases, [fzf.fish](https://github.com/patrickf1/fzf.fish) for fuzzy finding, and [nvm.fish](https://github.com/jorgebucaran/nvm.fish) for node version management.
- ✨ **Prompt:** [Starship](https://starship.rs) — a minimal, fast, customizable, and cross-shell prompt.
- 📝 **Editor:** [VS Code](https://code.visualstudio.com) — for code editing with extensions and AI agents.
- 🧠 **Languages:** C, C++, Java, Bash/Shell, and Windows Batch/CMD
- 🔄 **Version control:** [Git](https://git-scm.com)
- ⚡ **Static site generator:** [Hugo](https://gohugo.io) — a fast static site generator with a single binary and no runtime dependencies, powering my website.
- 🚀 **Hosting & infrastructure:** [Cloudflare Pages](https://pages.dev) and [DigitalOcean](https://digitalocean.com)
- 🟢 **Status monitoring:** [BetterStack](https://betterstack.com)
- 📊 **Analytics:** [Umami](https://umami.is) — privacy-first, cookieless analytics for my website.

### 🤖 AI

- 💬 **Assistant:** [ChatGPT](https://chatgpt.com), [Claude](https://claude.ai), [Gemini](https://gemini.google), and [Ollama](https://ollama.com) (local) — for brainstorming, research, learning, productivity, creative exploration, problem-solving, and feedback.
- 🛠️ **Coding & agents:** [GitHub Copilot](https://github.com/copilot) (primary coding assistant), [Codex](https://chatgpt.com/codex), [Claude Code](https://claude.ai/code), and [Antigravity](https://antigravity.google) — for coding, agentic development, and technical workflows.

### 📦 Applications

- ✉️ **Mail:** [Proton Mail](https://proton.me/mail) — for private, secure, and encrypted mail with [SimpleLogin](https://simplelogin.io) for email aliases.
- 📅 **Calendar:** [Proton Calendar](https://proton.me/calendar)
- 🔑 **Password manager:** [Bitwarden](https://bitwarden.com) and [Proton Pass](https://proton.me/pass)
- 🛡️ **Authenticator:** [Ente Auth](https://ente.com/auth) and [Proton Authenticator](https://proton.me/authenticator)
- 🌐 **Browser:** [Firefox](https://firefox.com) — I use a [hardened](https://www.privacyguides.org/en/desktop-browsers/#recommended-firefox-configuration) configuration for privacy.
  - **Main extensions**:
    - [uBlock Origin](https://addons.mozilla.org/en-US/firefox/addon/ublock-origin) (ad and content blocker)
    - [Violentmonkey](https://addons.mozilla.org/en-US/firefox/addon/violentmonkey) (userscripts)
    - [Stylus](https://addons.mozilla.org/en-US/firefox/addon/styl-us) (userstyles) — I use the [Catppuccin Mocha (Sapphire)](https://userstyles.catppuccin.com) theme for many websites.
    - [Dark Reader](https://addons.mozilla.org/en-US/firefox/addon/darkreader) (dark mode)
    - [Firefox Multi-Account Containers](https://addons.mozilla.org/en-US/firefox/addon/multi-account-containers) (separating personal, work, and other browsing)
- 💬 **Communication:** [Signal](https://signal.org), [WhatsApp](https://whatsapp.com), [Discord](https://discord.com), and [Element](https://element.io)
- 🗝️ **VPN & network privacy:** [Cloudflare WARP](https://one.one.one.one) and [Proton VPN](https://proton.me/vpn)
- 📝 **Notes:** [Obsidian](https://obsidian.md) and [Standard Notes](https://standardnotes.com)
- 🖼️ **Photos:** [Ente Photos](https://ente.com)
- 💳 **Wallet:** [Cake Wallet](https://cakewallet.com), [Coinbase Wallet](https://wallet.coinbase.com), and [Proton Wallet](https://proton.me/wallet)
- 🎮 **Game launchers:** [Steam](https://steampowered.com) (with [Proton](https://github.com/valvesoftware/proton)), [Lutris](https://lutris.net), [Heroic Games Launcher](https://heroicgameslauncher.com), and [Prism Launcher](https://prismlauncher.org)
- 🔁 **Windows compatibility:** [Bottles](https://usebottles.com) — for running Windows apps and games on Linux.
