This site is **designed and built with privacy in mind**. It uses **privacy-first, cookieless analytics** that collect aggregate information about site usage, such as pages visited, referrers, approximate country, and device/browser type. This information helps me understand which content people find helpful, how they navigate the site, and how the site and its content can be improved. The data is anonymized and **does not include personally identifiable information**. There is **no advertising, tracking cookies, or cross-site tracking**, and analytics are not used to build personal profiles.

## At a glance

| Service                      | Purpose                            | What it does                                                          |
| ---------------------------- | ---------------------------------- | --------------------------------------------------------------------- |
| **Cloudflare Pages**         | Hosting                            | Processes technical information needed to deliver and secure the site |
| **Umami Cloud**              | Primary analytics                  | Privacy-first, cookieless, anonymized usage statistics                |
| **Cloudflare Web Analytics** | Additional analytics & performance | Privacy-first, cookieless, aggregate usage and performance metrics    |
| **Giscus / GitHub**          | Comments                           | Stores comments as GitHub Discussions                                 |
| **Webmention.io / Bridgy**   | Webmentions                        | Processes publicly available web content                              |

## Hosting

The site is deployed and hosted on [**Cloudflare Pages**](https://pages.dev). Cloudflare may process standard technical information, such as IP addresses and user-agent information, as necessary to deliver, secure, and operate its infrastructure.

For more information, see [Cloudflare's Privacy Policy](https://cloudflare.com/privacypolicy).

## Analytics

[**Umami Cloud**](https://umami.is) is the primary analytics service used on this site. It collects anonymized information such as pages visited, referrers, country, browser, operating system, and device type. Umami does not store personally identifiable information and does not use cookies or track visitors across websites.

[**Cloudflare Web Analytics**](https://www.cloudflare.com/web-analytics) is also enabled through Cloudflare Pages. It provides additional traffic and performance metrics and does not collect or use visitors' personal data or track individual end users across different websites.

You can view the public, aggregate analytics for this site at **[agha.dev/analytics](https://agha.dev/analytics)**.

Neither analytics service is used for advertising, cross-site tracking, or building personal profiles.

For more information:

* [Umami privacy documentation](https://docs.umami.is/docs/faq)
* [Cloudflare Web Analytics documentation](https://developers.cloudflare.com/web-analytics/about)

## Comments

Comments are provided through [**Giscus**](https://giscus.app), which uses **[GitHub Discussions](https://github.agha.dev/agha.dev/discussions)** in this site's source repository. Posting a comment requires a GitHub account, and anything you post is publicly visible.

For more information, see [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Webmentions

This site supports Webmentions through [**Webmention.io**](https://webmention.io) and [**Bridgy**](https://brid.gy).

Interactions with posts here, such as replies, likes, reposts, and mentions from supported platforms, may appear on this site. These services process publicly available information associated with those interactions.
